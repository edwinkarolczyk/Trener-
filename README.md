# Trener 2

Osobna aplikacja treningowa Android rozwijana w repozytorium `edwinkarolczyk/Trener-`.

## Stan 0.3.0

- tryb solo i trening dla 2 osób na jednym telefonie,
- START / PAUZA / WZNÓW / STOP,
- automatyczne przerwy zależne od ćwiczenia,
- zapis ciężaru, powtórzeń, czasu i objętości,
- logika progresji: dołóż / zostaw / odejmij ciężar,
- plan PON / ŚR / PT + dodatkowy biceps,
- kreator treningu mieszanego z biblioteki ćwiczeń,
- historia treningów,
- ekran Postępy: masa ciała, rekordy, serie i objętość,
- lokalne zdjęcia sylwetki (maks. 12 skompresowanych zdjęć),
- przypomnienia treningowe Android z wyborem dni i godziny,
- odtwarzanie przypomnień po restarcie telefonu,
- eksport / import historii i ustawień do JSON.

## Dieta

Moduł jest obecnie tylko zaprojektowany wizualnie. Kalorie, białko, tłuszcze i węglowodany są celowo nieaktywne — liczenie kalorii zostanie dodane w późniejszym etapie.

## Następny etap

Synchronizacja dwóch telefonów w tej samej sieci Wi-Fi: wspólna sesja na żywo, ale osobne ciężary, przerwy, historia i progresja każdego użytkownika.

## Prywatność

Historia, masa ciała i zdjęcia sylwetki pozostają lokalnie na urządzeniu. Zdjęcia nie są wysyłane do GitHuba ani do chmury.
